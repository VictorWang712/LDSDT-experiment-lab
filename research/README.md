# research/：C 的记录

本目录由 C（观察记录员）维护，随仓库提交。字段与填写规范见课程网站「C 角色指南」。

| 文件 | 内容 | 频率 |
| --- | --- | --- |
| `observation_log.csv` | 工作片段观察，一行一个片段 | 课堂内全程；课外每周至少各观察 A、B 一次 |
| `incidents/INC-xxx.md` | 关键事件报告（复制 `INC-000-template.md`） | 卡住 ≥ 15 分钟、回滚重做、放弃 AI 改为手写时 |
| `sync_log.csv` | A、B 之间的每次交流 | 每次 |
| `decision_log.csv` | 设计决策 | 每个自由度维度做决定时 |
| `reports/subtask-N.md` | 子任务对比小结（复制模板） | 每个子任务截止前 |

CSV 用 UTF-8 编码；时间统一写成 `YYYY-MM-DD HH:MM`（本地时间，精确到分钟）。如实记录，记录内容不影响 A、B 的成绩。
